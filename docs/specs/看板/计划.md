### 再调整（同一天晚些）：要的是四个页面本身、维持原有样式

三块通用卡片那张页不是要的东西。改成：**四个页面（转化率监控 / 出单监控 / 商户流失 / 交易概览）原样**装进一张离线单文件。
做法（Chromium 上验过）：页面 HTML 不动；ES 模块经 importmap 映射成 data: URL（live binding 等语义不变）；
`fetch('/api/…')` 由前置脚本按事先抓好的响应回答（工作台进程里用 Flask test_client 抓，同一套路由）；
四页各一个 srcdoc iframe，外面套和首页一样的图标轨。`dashboard/offline.py`、`snapshot.py`（**不进口径清单**：要四个页面和全部 JS，看板仓库没有；`export.py` 在函数内才 import 它们）。
契约那张页（`static/dashboard.html` + `source.py`/`report.py`）留给看板仓库的服务用，工作台的 job 不再生成它。

**做法**（都在看板仓库，`board/` 是看板自己的代码，不同步）：

- `生成看板.py`：读 `--data`（默认取 `config.json` 的 `dashboard.workbench_data_dir`）→ 四块各自取最新一天的数据 →
  交易概览 / 商户流失在 Python 里用同步来的 `churn.trade` / `churn.overview` / `churn.funnel` / `churn.weekly` 算好嵌进去；
  出单监控嵌**原始台账**（页面里用同步来的 `order_monitor/analyze.js` 算，和工作台同一份）；
  转化率起 Node 跑 `board/转化率快照.mjs`（同步来的 `dataset.js` 读报表、`baseline.js` 按存档算三个周期的基准线），
  嵌 `ds` + 基准线，页面里用同步来的 `analyze.js` + `render/*.js` 现算现画。
- 页面 `board/模板.html`：工作台那套 token；三块自绘（改自工作台各页的 render，去掉控件）；转化率两个面板的骨架和 CSS
  **从同步来的 `static/conversion.html` 里抽**（所以清单里加了它），CSS 按块加前缀隔离，两边互不串。
  ES 模块经 importmap 映射成 data: URL（iframe 版验过的那条路，语义不变），页面里 `import` 同步来的口径模块。
- 出单监控和商户流失两块要的 JS（`order_monitor/analyze.js`、`churn/analyze.js`、`churn/overview.js`、`trade/analyze.js`、
  `shared/dom.js`）本来就在清单里。
