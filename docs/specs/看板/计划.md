  工作台的周是**周五 → 周四**、跟报表走（`§2.17.7`）。两个「本周 TPV」摆一起必然对不上。
- 公司看板「商户与代理商」是商户级；工作台流失的单位是**站点**（用户ID + 站点）。
- 公司看板「映射管理」和工作台的直签人 / 代理商 / 未分配BD 是同一件事的两份。
