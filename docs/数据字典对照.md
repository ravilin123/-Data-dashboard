## 已知的口径冲突（从公司看板截图看出来的，等字典再核）

抄自 `docs/specs/看板/计划.md` 末尾：

1. **周界**：公司看板的周从**周日**起（09-17 周四显示「本周已过 5/7 天」）；工作台的周是**周五 → 周四**、跟报表走，周号按结束日算（`§2.17.7`）。两个「本周 TPV」摆一起必然对不上。`churn/trade.py: build(anchor=…)` 已参数化，过渡期并存；改公司口径的事另谈。
2. **日界**：公司看板是「UTC+8 自然日」；工作台的一天是报表 `统计周期` 给的日期，口径层不做时区换算。要核两边的「今天」是不是同一段时间。
3. **站点 vs 商户**：公司看板「商户与代理商」是**商户级**；工作台流失的单位是**站点**（用户ID + 站点），交易大盘的排名才是商户级（合并站点）。一家七个站点在两边是 1 条和 7 条。
4. **映射管理 vs `agent_owner` / `bd_emails`**：公司看板的「映射管理」和工作台的直签人 / 代理商 / 未分配BD（`names.py`）、代理商ID → BD 映射（`churn.agent_owner`）、BD 姓名 → 邮箱（`order_monitor.bd_emails`）是同一件事的两份，要定谁为准。

要去问的五件事（同一份计划）：① 技术栈 ② 有没有站点级 / 商户级明细接口 ③ 映射管理谁为准 ④ 数据字典 ⑤ 改周口径找谁谈。
